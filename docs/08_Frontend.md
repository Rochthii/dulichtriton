# 08. GIAO DIỆN WEB PORTAL (FRONTEND PORTAL)

## 1. Công nghệ Frontend
* **Tech Stack**: HTML5 / Vanilla CSS / Modern JS (hoặc Vite React + TailwindCSS).
* **Bản đồ**: Leaflet JS + OpenStreetMap / Google Maps Embed.
* **Phong cách**: Mobile-First, thiết kế hiện đại, màu sắc tự nhiên (xanh lá, vàng nâu thốt nốt, mộc mạc Bảy Núi).

## 2. Cấu trúc trang Web Portal
* **Trang chủ (`/`)**: Banner ấn tượng, ô hỏi AI Chatbot nổi bật, top địa điểm hot, video nổi bật.
* **Trang địa điểm (`/places`)**: Bộ lọc danh mục (Thiên nhiên, Văn hóa, Check-in) & Xã/Thị trấn, thẻ thông tin + video embed.
* **Trang ẩm thực (`/food`)**: Đặc sản Tri Tôn, danh sách nhà hàng/quán ăn.
* **Trang lưu trú (`/stay`)**: Homestay, cà phê view đẹp, nhà nghỉ.
* **Trang bản đồ (`/map`)**: Bản đồ vệ tinh/tương tác hiển thị 82 điểm master.
* **Trang lịch trình (`/itinerary`)**: Công cụ chọn số ngày và sinh lộ trình chi tiết.
* **Widget AI Chatbot**: Nút chat nổi góc màn hình, mở khung chat tương tác trực tiếp.
